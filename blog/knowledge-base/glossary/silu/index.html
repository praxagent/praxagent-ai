SiLU

The activation that multiplies a number by its own sigmoid, smooth through zero.

SiLU (sigmoid linear unit), also called swish, multiplies a number by the sigmoid of itself:

\[ \mathrm{SiLU}(x)=x\,\sigma(x)=\frac{x}{1+e^{-x}}. \]

The sigmoid is smooth, and so is this product. In particular there is no corner at \(0\): \(\mathrm{SiLU}(0)=0\) and the slope there is \(1/2\). In the models in this project, SiLU is the nonlinearity inside the gated feed-forward block. One branch of that block is passed through SiLU and then multiplied by the other branch.

Worked example

\[ \begin{aligned} \mathrm{SiLU}(0) &= 0,\\ \mathrm{SiLU}(1) &= \frac{1}{1+e^{-1}} \approx 0.7311,\\ \mathrm{SiLU}(-1) &= \frac{-1}{1+e^{1}} \approx -0.2689. \end{aligned} \]

Negative inputs are not clipped to zero. They are shrunk toward zero, because the sigmoid of a large negative number is small.

from math import exp

def silu(x: float) -> float:
    return x / (1.0 + exp(-x))

SiLU is a scalar function applied coordinate by coordinate inside a block. It is not a next-token probability, and applying it does not by itself produce a vocabulary distribution.
