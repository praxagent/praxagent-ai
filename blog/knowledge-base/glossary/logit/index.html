Logit

An unnormalized next-token score. Softmax turns a vector of logits into probabilities.

A logit, in these notes, is one unnormalized score for a vocabulary token, before that score is turned into a probability. The unembedding produces a vector \(z\), with one logit \(z_v\) for each token \(v\) in the vocabulary \(V\). Softmax converts the vector into the next-token distribution:

\[ p_v=\frac{\exp(z_v)}{\sum_{u\in V}\exp(z_u)}. \]

A logit is not a probability. It can be negative, and it has no fixed range. Adding the same number to every logit leaves every probability unchanged, because that number cancels between the numerator and the denominator. The differences are log probability ratios:

\[ z_i-z_j=\log\frac{p_i}{p_j}. \]

The token with the largest logit is the one a greedy continuation emits. Dividing every logit by a positive temperature changes the probabilities and preserves which logit is largest.

This is not the binary log-odds function \(\operatorname{logit}(p)=\log\frac{p}{1-p}\), which sends one probability to one number. A language-model logit vector is the input to softmax over the whole vocabulary. When the choice is between exactly two tokens, the difference of their logits equals that log-odds.

Worked example

The same scores as on the greedy-continuation page:

Token Logit \(z\) Probability, rounded to 3 decimals
red 3.2 0.612
blue 2.7 0.371
green -0.4 0.017

The unrounded weights are \(\exp(z-\max z)\), then divided by their sum. green is negative and still has positive probability. red is the greedy token because \(3.2\) is the largest logit, not because \(0.612\) is a calibrated chance that the token is correct. Shifting every logit by \(+5\), to \(8.2\), \(7.7\), and \(4.6\), returns the same three probabilities. The log ratio of red to blue is \(3.2-2.7=0.5\).

from math import exp

def softmax(logits: list[float]) -> list[float]:
    """Turn unnormalized scores into probabilities that sum to one."""
    if len(logits) == 0:
        raise ValueError("logits must be nonempty")
    maximum = max(logits)  # Cancels in the ratio; keeps exp in range.
    weights = [exp(logit - maximum) for logit in logits]
    total = sum(weights)
    return [weight / total for weight in weights]

A logit lens is a separate procedure: it applies this same kind of readout to a mid-layer state. Those scores are logits only under the readout the analyst specified. They are not automatically the model’s next-token logits.
