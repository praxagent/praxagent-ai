RMS normalization

Rescaling a vector by its root mean square, then by a learned gain on each coordinate.

RMS normalization rescales a hidden vector by its root mean square, then multiplies each coordinate by a learned gain. For a vector \(h\in\mathbb{R}^d\) and a gain vector \(g\),

\[ \mathrm{RMS}(h)=\sqrt{\frac{1}{d}\sum_{i=1}^{d} h_i^2+\varepsilon}, \qquad y_i=g_i\frac{h_i}{\mathrm{RMS}(h)}. \]

The constant \(\varepsilon>0\) keeps the quantity inside the square root at least \(\varepsilon\), including at \(h=0\). The map is therefore smooth at the origin. Qwen models use this in place of a layer normalization that would also subtract the mean. The mean is not removed here: a vector and a shifted copy of itself are treated differently.

Worked example

Take \(h=(3,4)\), \(d=2\), \(\varepsilon=0\), and \(g=(1,1)\). The mean of the squares is \((9+16)/2=12.5\), and

\[ \mathrm{RMS}(h)=\sqrt{12.5}\approx 3.5355. \]

The normalized coordinates are \(3/3.5355\approx 0.8485\) and \(4/3.5355\approx 1.1314\). With the models’ positive \(\varepsilon\), typically \(10^{-6}\) or \(10^{-5}\), the change is far smaller than these four digits. At \(h=(0,0)\), \(\mathrm{RMS}=\sqrt{\varepsilon}\) and \(y=0\).

def rms_normalize(values, gain, epsilon=0.0):
    if len(values) == 0 or len(values) != len(gain):
        raise ValueError("values and gain must be nonempty and the same length")
    if epsilon < 0:
        raise ValueError("epsilon must be nonnegative")
    mean_square = sum(value * value for value in values) / len(values)
    scale = (mean_square + epsilon) ** 0.5
    return [g * value / scale for g, value in zip(gain, values)]

The output is a hidden vector, not a vector of vocabulary scores. Those scores appear only after the unembedding.

See also: residual stream, unembedding.
