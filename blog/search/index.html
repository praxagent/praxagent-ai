Keyword and meaning-aware search

Keyword search is small and starts first. Meaning-aware search then runs privately in this browser. Its first use downloads about 47 MB of model and runtime files; the browser can cache them for later searches. Meaning-aware search starts with three or more non-space characters.

Your browser has data-saving mode enabled, so the larger download will not start unless you choose to enable it.
