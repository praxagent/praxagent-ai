The original report.html bytes are also supplied as report.html.txt, because Hugo treats HTML extensions inside a leaf bundle as content. Download report.html.txt as report.html and keep its trajectory.png, report.pdf, trajectory.pdf, receipt.json and data.json alongside it. Open report.pdf for a direct browser view. Both HTML copies are byte-identical to the audited source report. The publication checker accepts this one filename alias when checking the built download bundle. The source receipt retains original archive paths. The original generator needs the full raw case and its plotting/PDF dependencies for --verify; the page-local checker needs Python and NumPy only and performs no model execution.
