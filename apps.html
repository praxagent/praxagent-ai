Sample Apps

AI-powered applications built with purpose and practicality.

Prax

Personal AI assistant for the web, Discord, SMS, and voice. Prax is the agent orchestrator: a LangGraph ReAct system with 97+ tools, plugin extensibility, git-backed memory, and specialized sub-agents.

Prax browses the web, writes and reviews code, creates deep-dive notes, takes screenshots, generates presentations, and learns across sessions. It now connects to TeamWork for the shared collaboration UI and Prax Sandbox for browser, desktop, terminal, and code execution.

  • Agent/orchestrator for web, Discord, SMS, and voice
  • 97+ tools with an extensible plugin system
  • Git-backed memory with vector and graph retrieval
  • Designed to pair with TeamWork and Prax Sandbox

Prax Sandbox

Standalone, plug-and-play code execution sandbox for agentic harnesses. It was carved out of Prax so any agent framework can use the same browser, desktop, terminal, and coding-agent environment.

A long-running Docker container runs OpenCode, Claude Code, Codex, Chromium via CDP, a noVNC desktop, and a full toolchain. A small Python client drives sessions without depending on Prax.

  • Dockerized execution environment for agent harnesses
  • Chromium CDP, noVNC desktop, and coding agents
  • Python client API with no Prax dependency
  • Remote daemon mode over TLS and bearer auth

TeamWork

Agent-agnostic collaboration shell: a Slack-like web UI for AI agent teams. TeamWork provides the body -- chat, channels, task board, file browser, embedded terminal, and live browser screencast -- while your agent provides the brains.

Use it with Prax or any agent framework through a simple REST + WebSocket API. TeamWork itself has zero AI dependencies and requires no LLM API keys.

  • Agent-agnostic REST + WebSocket API
  • Real-time chat, channels, DMs, and mirrored conversations
  • Kanban task board and in-browser file workspace
  • Embedded terminal, browser screencast, and live agent output
