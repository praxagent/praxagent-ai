Sparse Autoencoders

Studying learned feature dictionaries as measurable coordinates rather than treating human-assigned feature labels as self-validating explanations.

Current work maps public SAE features across controlled text categories, tests label validity and confounds, and separates descriptive activation evidence from causal claims.

  • Public-weight feature activation mapping
  • Balanced contrasts, controls, and uncertainty
  • Feature-ID primers and reproducible analysis
